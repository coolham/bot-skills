# bot-skills

Shared Grok Bot skills. Every agent uses the same layout and authoring rules.

## Layout

- `skills/<skill-id>/SKILL.md` — one skill per folder (`skill-id` is kebab-case)
- `docs/skill-spec.md` — **authoring standard** (required reading before adding a skill)

## Authoring

Before creating or changing a skill, follow [docs/skill-spec.md](docs/skill-spec.md) and the shared skill [Skill authoring standards](skills/skill-authoring-standards/SKILL.md).
